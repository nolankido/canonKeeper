Let your AI assistant buy the audits

Everything on this site is also an MCP server, so an assistant such as Claude can quote an audit, pay for it and read the findings back to you. It works inside limits you set with PayPal: it never holds a PayPal login or key, and only you can approve a payment.

1. Connect it

  • Claude (web or desktop): add a custom connector and paste the address above.
  • Claude Code: claude mcp add --transport http preflight {{ mcp_url }}
  • Any other MCP client that speaks streamable HTTP: the same address.

2. Ask for what you want

  1. “Open a $20 Preflight budget.” It replies with a PayPal link. You approve it; the assistant cannot.
  2. “Audit the Saltmarsh demo series and pay from the budget.” It quotes, pays and waits for the report.
  3. “Check the demo draft against the series.” It reads back each contradiction with both passages.
  4. “Close the budget.” What is left goes back to your PayPal account.

For your own books, ask it for an upload link: you upload the files on this site and see the price before anything is bought.{% if trains_on_prompts %} This site runs on a free AI tier that may use submitted text for training, so public-domain books only.{% endif %}
